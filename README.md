# Proyecto-final-de-DS3
Aplicación desarrollada como proyecto académico para implementar un sistema de monitoreo utilizando las herramientas y tecnologías trabajadas durante el curso.
Descripción

Este proyecto consiste en el desarrollo de un sistema de monitoreo cuyo código fuente se encuentra disponible en este repositorio, junto con archivos que facilitan su ejecución y revisión.

El objetivo es presentar la implementación realizada durante el curso y permitir que otras personas puedan consultar el código, ejecutar la aplicación y conocer su funcionamiento.
Estructura del repositorio
Proyecto-final-de-DS3/
├── proyectoArduino/
│   └── Código fuente del proyecto
├── Sistema de monitoreo(Diego Torres).zip
└── README.md

Cómo ejecutar el proyecto
Opción 1: Ejecutar la aplicación
Descarga o clona este repositorio.
Busca el ejecutable .exe dentro de la carpeta out del proyecto.
Ejecuta el archivo para iniciar la aplicación.

Nota: La ejecución del programa depende de que el equipo cuente con los requisitos necesarios para utilizar la aplicación.

Opción 2: Descargar el archivo ZIP
Descarga Sistema de monitoreo(Diego Torres).zip desde este repositorio.
Extrae su contenido en una carpeta.
Busca el ejecutable incluido en el archivo comprimido.
Ejecuta la aplicación.
Opción 3: Clonar el repositorio
git clone https://github.com/diwgod55/Proyecto-final-de-DS3.git
cd Proyecto-final-de-DS3

Después, abre la carpeta del proyecto y localiza el archivo ejecutable.
Tecnologías

El proyecto incluye código fuente y archivos de una aplicación de monitoreo. Las tecnologías específicas y sus versiones deben confirmarse a partir del código fuente.
